# Instruções de Pesquisa Web

Quando o usuário solicitar informações recentes, notícias ou dados externos à base local de notas:
1. Utilize a ferramenta `executar_script_skill` informando a skill `web-search`, o script `search.py` e a query como argumento.
2. Analise os dados retornados em formato JSON.
3. Formule uma resposta objetiva, referenciando as fontes e links relevantes.
